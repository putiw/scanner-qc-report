# Scanner upgrade QC report

[View the report](https://putiw.github.io/scanner-qc-report/)

Phantom and human MRI comparisons before and after the Prisma-to-Cima.X upgrade, including anatomical, diffusion and functional imaging.

This repository contains the rendered report, figure assets and interactive viewers. Raw MRI scans, analysis workspaces and internal acquisition links are not included. The report describes its sample sizes, methods and limitations.

GitHub Pages publishes the site after changes to the main branch. Cortical viewers load losslessly compressed data; event responses are loaded on demand for the selected protocol and TR. Inter fonts are distributed under the SIL Open Font License in `site/ari_scanner_qc_report_assets/fonts/OFL.txt`; embedded visualization-library notices are retained.
